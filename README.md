# Ídolo del Astillero — sitio informativo

Sitio estático independiente sobre Barcelona Sporting Club, hecho con HTML, CSS y JavaScript. No necesita instalación, servidor ni base de datos.

## Contenido

- `index.html`: textos y secciones de la página.
- `app.js`: cronología y menú móvil.
- `styles.css`: colores, diseño y adaptación a celulares.

## Actualizar el sitio

En GitHub, abre el archivo que quieres cambiar, pulsa el lápiz para editar y confirma con **Commit changes**. Los cambios publicados en la rama `main` se reflejan en GitHub Pages.

La cronología se edita en la lista `moments` de `app.js`. Los resultados, plantilla y noticias actuales enlazan a fuentes oficiales para evitar que este sitio independiente muestre datos desactualizados.

## Publicación

GitHub Pages sirve este sitio estático desde la rama `main`, carpeta raíz. La dirección gratuita es https://sword7368-hue.github.io/barcelona-ecuador/ . Un dominio propio se compra aparte.

Esta página es independiente y no representa oficialmente a Barcelona Sporting Club. No tiene cuentas ni recopila datos personales.
